## 2. Logic Chain

1. **Web / Desktop Parity:**
   - Observation 1 demonstrates that all major operations portals (Supplier, Warehouse, Factory, Retailer) are built on Next.js 15, React 19, and Tailwind CSS v4, and are bundled as hybrid desktop apps via Tauri v2.
   - The existence of `@pegasusx/desktop-cache` and `@pegasusx/desktop-bridge` ensures that local SQLite-backed offline mutations and native hardware features (printing, deep-links) are available across all desktop apps.

2. **Mobile Parity & Architecture:**
   - Observation 2 demonstrates that all 6 business roles have native Kotlin Android apps and native SwiftUI iOS apps.
   - Both mobile platforms share centralized monorepo modules (`mobile-android-design`, `mobile-android-kit`, `mobile-ios-core`, `mobile-ios-kit`) ensuring parity of UI themes, MarketPack session state, cell routing, and offline queue semantics.

3. **Contract Rigor & Zero Drift:**
   - Observation 3 confirms that contract generation is automated from Go backend AST annotations (`cmd/gen-contracts`) into JSON-Schema (`contracts/events.schema.json`) and consumed by Quicktype for Kotlin and Swift code generation.
   - The successful zero-exit run of `role_row_contract_check_full.sh` proves mathematically that all HTTP paths requested by any client application exist as registered routes in the backend Go router.

4. **Geospatial & Realtime Compliance:**
   - Observation 4 confirms that MapLibre GL and Carto Positron vector tiles have completely replaced legacy Mapbox SDKs.
   - Dynamic pack camera binding (`mapInitialViewState`) prevents hardcoded city coordinates, adhering strictly to multi-market cell isolation.
   - Telemetry services on Android and iOS adhere to the dual telemetry `/v1/ws?sv=2` protocol.

5. **Layer A vs Layer B Honesty:**
   - Disabled and out-of-scope features (saved cards, legacy AI predictions alias, inventory audit, quantity negotiation) return honest HTTP 410 codes rather than mock 200 responses or empty stubs.
