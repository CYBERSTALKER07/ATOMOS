# Surface Skill: Web & Desktop Portals

Governs Next.js 15 App Router, React 19, TypeScript, Tailwind CSS, and Tauri v2.
Enforce:
- Absolute Zero Shared UI Packages (local component ownership in `components/ui/`).
- Enterprise SWR caching with optimistic updates and offline degradation.
- Secure Tauri v2 IPC bridge.
- Pegasus Monochrome theme (`bg-neutral-900`, `border-neutral-800`, `text-neutral-100`).
