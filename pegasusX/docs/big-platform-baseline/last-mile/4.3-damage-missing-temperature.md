# 4.3 Damage / Missing / Temperature Dual-Wire

> **PLANNING BASELINE** — not living runtime status. Prefer [`../DOCS_SOURCE_OF_TRUTH.md`](../DOCS_SOURCE_OF_TRUTH.md) and code for what is shipped.


## Capability

- Photo + barcode + optional temperature log  
- Exception ticket + optional **claim pre-fill**  
- On supplier approve: **reverse logistics ticket** (dock OPEN)  

## Existing anchors

- Exception report / missing items dual-wire  
- Claims bridge from driver exception  
- Media upload ticket (GCS)  
- Returns inbound OPEN filter; claim notes  

## Types

`DAMAGED | MISSING | CONCEALED_DAMAGE | TEMPERATURE | TAMPER | OTHER`

## Rules

- Photo required for DAMAGED / WRONG_ITEM-class.  
- Claim pricing from **order lines only**.  
- Window from COMPLETED (default 48h).  

## Edge cases

| Case | Rule |
|------|------|
| Photo upload fails | Placeholder pilot vs block terminal claim types |
| Duplicate exception | Idempotent by order+sku+type |
| Approve without stock path | Ticket still created for audit |
