# 4.1 Shop-Closed / No-Answer Protocol (Enhanced)

> **PLANNING BASELINE** — not living runtime status. Prefer [`../DOCS_SOURCE_OF_TRUTH.md`](../DOCS_SOURCE_OF_TRUTH.md) and code for what is shipped.


## Wire status mapping

| Design status | Live wire status |
|---|---|
| `SHOP_CLOSED_PENDING` | `ARRIVED_SHOP_CLOSED` |
| Credit leave | `DELIVERED_ON_CREDIT` |
| Return / cancel | `CANCELLED` + `ShopClosedResolution=RETURNED\|CANCELLED` |

Partial delivery is **not** a top-level status: `Orders.PartialDelivery` + line fields on `LineItemsJson`.

## Existing anchors

- `ARRIVED` → `ARRIVED_SHOP_CLOSED` (`POST /v1/delivery/shop-closed`)
- Grace: `SHOP_CLOSED_GRACE_MINUTES` (bootstrap default 5; design target 30–45)
- Retailer: `POST /v1/retailer/shop-closed-response`
- Supplier: `GET /v1/supplier/shop-closed/active`, `POST /v1/supplier/shop-closed/resolve`
- Events: `SHOP_CLOSED`, `SHOP_CLOSED_RESPONSE`, `SHOP_CLOSED_ESCALATED`, `SHOP_CLOSED_RESOLVED`, `SHOP_CLOSED_BYPASS_OFFLOAD`, `SHOP_CLOSED_TIMEOUT`, `CREDIT_LEAVE`

## Schema (migration `20260729_shop_closed_proximity_partial.ddl`)

Orders additive columns:

- `ShopClosedAt`, `ShopClosedReason`, `ShopClosedGraceEndsAt`, `ShopClosedResolution`
- `PartialDelivery`, `ProximityUnlockedAt`, `ProximityMethod`

`OrderShopClosedLog` interleaved under Orders (audit of MARKED_CLOSED / RESPONDED / TIMEOUT / BYPASS).

Line-level qty lives in **LineItemsJson** (`delivered_qty`, `remaining_qty`, `offload_status`, `offload_reason`) — no separate `OrderLines` table.

## Timeout decision matrix

Pure function: `order.DecideShopClosedTimeout` (`shop_closed_timeout.go`).

| Condition | Resolution |
|---|---|
| Profile FROZEN / BLACKLISTED / CLOSED | `RETURN_TO_WAREHOUSE` |
| Risk HIGH (no force bypass) | `RETURN_TO_WAREHOUSE` |
| Credit available + LOW/MEDIUM | `CREDIT_LEAVE` |
| Credit blocked + `ForceBypassEnabled` | `FORCE_BYPASS` |
| Low value + soft threshold | `RESCHEDULE` |
| Else | `RETURN_TO_WAREHOUSE` |

**Race rule:** retailer response while still `ARRIVED_SHOP_CLOSED` always wins over timeout worker.

## Retailer response codes

Legacy: `OPEN_NOW`, `5_MIN`, `CALL_ME`, `CLOSED_TODAY`.

Enhanced: `RESCHEDULE`, `CREDIT_LEAVE`, `CANCEL`, `AUTHORIZE_BYPASS` (photo required).
