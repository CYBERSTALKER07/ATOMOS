# 4.4 Rescue & Dynamic Capacity Sharing

> **PLANNING BASELINE** — not living runtime status. Prefer [`../DOCS_SOURCE_OF_TRUTH.md`](../DOCS_SOURCE_OF_TRUTH.md) and code for what is shipped.


## Capability

- Driver requests rescue.  
- System ranks nearby capacity: remaining volume + ETA + **driver score**.  
- Accept → temporary multi-driver / multi-manifest handoff.  

## Existing anchors

- Driver rescue request/respond  
- Warehouse rescue preview/propose  
- Capacity / VU on vehicles  

## Ranking sketch

```
score = α*(1/eta_min) + β*(remaining_vu/order_vu) + γ*driver_score - δ*risk
```

## Edge cases

| Case | Rule |
|------|------|
| No capacity in radius | Escalate to warehouse dispatch replan |
| Accept then cancel | Release freeze; notify original driver |
| Fiscal open on original | Transfer rules must not orphan money state |
