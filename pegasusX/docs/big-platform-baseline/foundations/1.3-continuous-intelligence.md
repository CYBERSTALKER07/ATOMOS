# 1.3 Continuous Intelligence Layer

> **PLANNING BASELINE** — not living runtime status. Prefer [`../DOCS_SOURCE_OF_TRUTH.md`](../DOCS_SOURCE_OF_TRUTH.md) and code for what is shipped.


## Inputs

Kafka stream of:

- Orders, status, claims, fiscal results  
- Telemetry / spatial  
- Credit freezes, shop-closed, exceptions  
- External signals (Phase 1+): weather, events, promo, competitor price  

## Capabilities

1. **Anomaly detection** — rate spikes (claims, shop-closed, FISCAL_FAILED, cash shortfall).  
2. **Root-cause linking** — anomaly → knowledge-graph nodes (SKU, warehouse, driver, retailer).  
3. **Agentic suggestions** — default **human-in-the-loop** accept/reject with audit (existing AI recommendation pattern).  

## How it works

```
Kafka event → feature extract → score → (optional) AI_RECOMMENDATION_CREATED
  → role client shows suggestion → AI_RECOMMENDATION_DECIDED
  → optional mutation via normal APIs (never bypass state machine)
```

## Existing anchors

- `EventAIRecommendationCreated` / `Decided`  
- Supplier AI recommendations UI  
- Retailer AI predictions confirm/reject  
- `ai-worker` freeze registry + import consumers  

## Non-goals (v1)

- Fully autonomous money moves  
- Autonomous fiscal force-complete
