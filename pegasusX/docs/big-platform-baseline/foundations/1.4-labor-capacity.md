| Object | Dimensions |
|--------|------------|
| Warehouse | Volume, weight, labor hours, dock slots, skill |

## Freeze locks (extend existing)

Today: warehouse dispatch freeze locks + ai-worker freeze registry.  

**Extend to:**

- Labor slots (shift segment × skill)  
- Dock appointments  
- Driver shift calendar  

Same pattern: acquire → work → release; events `FREEZE_LOCK_*`.

## Math (sketch)

```
slot_available = capacity_units - sum(reserved_units) - frozen_units
assignment_ok iff demand_units <= slot_available
```
