# 8.3 Offline-First Driver + Cryptographic Manifest Verification

## Existing anchors

- Offline hashes / nonces on driver manifest  
- Offline verify UX  

## Target

- Download **signed** manifest + nonces.  
- Offline confirms (partial + exceptions) later reconcile by hash.  
- No double-spend money, no double-release inventory.

## How it works

```
Server: sign(manifest_payload, server_key) → driver
Driver offline: append actions + local_sig(nonce)
Sync: verify nonce unused, apply CAS, mark nonce used
```

## Edge cases

| Case | Rule |
|------|------|
| Replay offline batch | Nonce single-use |
| Server state advanced | Reject conflicting offline complete; keep exception trail |
