# 8.2 Fiscal-Aware State Machine + Regime Versioning

## Differentiator

Fiscalization is a **hard, non-bypassable gate** with document lifecycle and **versioned tax rules**. Historical COMPLETED stays correct when rates change.

## Existing anchors

- ADR-009: capture → FISCALIZING → COMPLETED / FISCAL_FAILED  
- `FISCAL_PROVIDER=PEGASUS` today; MY_SOLIQ deferred  
- Force-complete audited  

## Target

- On COMPLETED/force: EHF JSON, EDS sign, Soliq submit (regulatory/).  
- Order stores `fiscal_regime_version_id` at completion.  
- Force-complete still generates correct historical fiscal artifact.

## Edge cases

| Case | Rule |
|------|------|
| Rate change mid-route | Use regime at COMPLETED, not at order create |
| Soliq down | Retry queue; admin force only with audit |
| Multi-line multi-VAT | Per-line regime snapshot |
