# 8.7 Dynamic Credit + Fiscal Freeze Across Partition

## Rule

Credit freeze and fiscal freeze are **durable Spanner states**, not Redis-only.

- Clients and workers respect freezes even if Redis or Kafka lag.  
- Redis may cache for speed; Spanner is authority.

## Existing anchors

- Credit status FROZEN  
- Open fiscal count blocking driver shift end  
- Dispatch freeze locks  

## Edge cases

| Case | Rule |
|------|------|
| Cache says active, Spanner frozen | Spanner wins on mutation |
| Force-complete while fiscal open | Admin-only + audit |
