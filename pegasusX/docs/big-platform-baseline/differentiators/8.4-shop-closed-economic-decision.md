# 8.4 Shop-Closed + Credit-Leave as First-Class Economic Decision

See also: `last-mile/4.1-shop-closed-protocol.md`.

## Differentiator

Not only a UI flow — system computes **expected cost** of return vs credit leave vs reschedule using:

- Retailer risk tier  
- Order margin (minor)  
- Credit utilization bps  
- Second-visit cost  

Recommendation shown to driver + retailer; decision feeds risk models.

## Edge cases

| Case | Rule |
|------|------|
| Frozen credit | Credit-leave removed from options |
| High claim velocity | Prefer return/reschedule |
