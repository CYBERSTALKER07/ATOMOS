# 8.6 Payload Seal as Explicit Role

> **PLANNING BASELINE** — not living runtime status. Prefer [`../DOCS_SOURCE_OF_TRUTH.md`](../DOCS_SOURCE_OF_TRUTH.md) and code for what is shipped.


## Differentiator

Most suites fold loading into WMS. PegasusX has an explicit **Payload** role:

- Seal event as hard handoff to driver  
- Capacity lock  
- Late **inject** with capacity check  
- Exception when cannot load  

Prevents “truck left with wrong goods” silent failure.
