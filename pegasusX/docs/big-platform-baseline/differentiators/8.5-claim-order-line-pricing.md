# 8.5 Claim Pricing From Original Order Lines + Auto-Approve

## Existing (strong)

- AggregateClaimLines  
- Cap vs order ceiling  
- 48h window  
- LEDGER_ONLY | STORE_CREDIT | GATEWAY_REFUND  
- Optional `CLAIM_AUTO_APPROVE_MAX_MINOR`  
- INTERNAL cash clawback  

## Extension

- Auto **insurance claim** when amount ≥ threshold **and** photo evidence present.  
- Never accept retailer-supplied unit prices as settlement truth.

## Fraud edges

| Attack | Defense |
|--------|---------|
| Inflated claim amount | Order-line prices only |
| Split-line qty bypass | Aggregate by SKU |
| Multi-claim same qty | Cumulative caps |
| Cross-retailer claim | IDOR + supplier scope |
