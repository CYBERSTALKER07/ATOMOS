# 2.4 Supplier Collaboration Portal (multi-tier)

## Capabilities

- Forecast share (downstream demand signals)  
- Capacity commit (factory/warehouse)  
- Automated PO within tolerance bands  
- Exception rooms (capacity shortfall, late lane)

## Tenancy

Supplier sees **only own nodes**. Commits become **binding constraints** for the planning engine.

## How it works

```
Demand signal → supplier reviews → CapacityCommit event
  → planning treats commit as hard constraint
  → deviation → alert + auto-replenishment options
```

## Anchors

Existing: topology, supply lanes, replenishment, AI recommendations, broadcast WS rooms.
