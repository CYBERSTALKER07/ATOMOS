# 2.3 Scenario & What-If Workbench

## Flow

1. Clone current baseline plan → `scenario_id`.  
2. Mutate inputs: demand, capacity, cost, tax rate, road closure.  
3. Re-optimize.  
4. Compare side-by-side: cost, service, cash, **fiscal impact**.  
5. Publish winner → new baseline with full audit.

## UI owners

- Supplier planning portal (primary)  
- Control tower views (read-only compare)  

## Edge cases

| Case | Rule |
|------|------|
| Publish while execution mid-flight | Scenario applies only to future waves; no rewrite of sealed manifests |
| Tax rate what-if | Uses versioned tax engine (regulatory/) for projected fiscal, not live rewrite of past COMPLETED |
