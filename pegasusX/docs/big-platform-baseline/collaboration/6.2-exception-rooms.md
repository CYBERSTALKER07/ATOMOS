# 6.2 Broadcast + Exception Rooms

## Extend WS rooms into structured rooms

| Room type | Suggested actions |
|-----------|-------------------|
| Shop closed | Reschedule / credit / cancel |
| Damage | Claim pre-fill / reverse ticket |
| Capacity | Unselect / rescue / second truck |
| Fiscal fail | Retry / force (admin) |

One-click accept/reject with audit (same pattern as AI recommendations).
