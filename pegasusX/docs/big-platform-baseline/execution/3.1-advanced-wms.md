# 3.1 Advanced Warehouse Management

> **PLANNING BASELINE** — not living runtime status. Prefer [`../DOCS_SOURCE_OF_TRUTH.md`](../DOCS_SOURCE_OF_TRUTH.md) and code for what is shipped.


## Capabilities

| Capability | Description |
|------------|-------------|
| Slotting | Velocity + affinity + temperature class |
| Wave / batch | Labor-balanced pick waves |
| Putaway / pick / pack / stage | Task state machines + capacity reservation |
| Robotics / AMR | Vendor-agnostic adapter interface |
| Yard & dock appointments | Linked to TMS ETAs |

## How it works

- Every task = state machine + capacity reservation.  
- Freeze locks prevent double-assignment.  
- Productivity metrics feed labor model.  

## Existing anchors

- Inventory positions, ops settings, dispatch locks, returns dock scan, stock commitments.  

## Edge cases

| Case | Rule |
|------|------|
| Task abandon mid-pick | Release reservation; partial qty audit |
| Slot full | Re-slot suggestion; no silent overwrite |
| AMR offline | Fall back to manual task queue |
