# 3.2 Full Transportation Management

## Capabilities

- Multi-modal adapters (road primary; rail/air/ocean later)  
- Continuous moves / backhaul detection  
- Carrier tendering + rate cards (even with private fleet primary)  
- Freight audit & settlement (minor units)  
- **Predictive ETAs**: telemetry + traffic + weather + historical stop times  

## Continuous replan loop

```
Disruption (shop closed, breakdown, road closure)
  → re-optimize remaining stops
  → value-at-risk prioritization (margin × risk × SLA)
  → publish new stop sequence / rescue
```

## Existing anchors

- Warehouse/supplier dispatch preview/execute (`optimizerclient` → OR-Tools when healthy; else heuristic)  
- Route geometry: Google Routes → OSRM → dense (see [`../../OPTIMIZER_AND_ROUTING_RUNTIME.md`](../../OPTIMIZER_AND_ROUTING_RUNTIME.md))  
- Driver telemetry, reassign, rescue request/respond  
- Manifest seal / depart  

## Edge cases

| Case | Rule |
|------|------|
| Replan after seal | Payload/driver gate rules; may require re-seal policy |
| Carrier reject tender | Fallback private fleet or next carrier |
| ETA confidence low | Show band not point; no premature settlement unlock (see last-mile proximity) |
