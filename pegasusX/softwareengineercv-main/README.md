# Fullstack Engineer Portfolio

This is a portfolio website for a fullstack engineer, built with Next.js, Tailwind CSS, and GSAP animations.

## Features

- Hero section with introduction
- About section
- Skills section with progress bars
- Projects section
- Contact form with API endpoint

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- GSAP
