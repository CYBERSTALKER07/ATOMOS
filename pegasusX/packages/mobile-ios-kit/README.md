# PegasusKit (mobile-ios-kit)

Shared iOS field-layer kit (§8.8): offline queue record + HTTP flush semantics + reconnect backoff.

```swift
// Package.swift product: PegasusKit
import PegasusKit
```

Add as a local Swift package in Xcode / XcodeGen:

```yaml
packages:
  PegasusKit:
    path: ../../packages/mobile-ios-kit
```
